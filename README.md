## Featured projects

### 1. Customer Segmentation for Marketing Prioritisation (M.Sc. thesis project)
RFM + CLV features, PCA (22 components, 95% variance) and three clustering methods compared (K-Means, Agglomerative/Ward, DBSCAN) on 4,999 customers.
Best model: Agglomerative, 2 clusters (silhouette 0.324, Davies-Bouldin 1.07). DBSCAN found no meaningful structure. Cluster separation is moderate, and the repo documents the limitations.
`Python · pandas · scikit-learn · PCA`
→ [Repo](https://github.com/simafaramarzi/Optimizing-Marketing-Strategies-Using-Customer-Segmentation-ML)

### 2. Natural-Language Data Query Agent (LLM + SQL)
An LLM agent using OpenAI function calling that turns plain-English questions into SQL over a Berlin housing dataset (SQLite). Destructive statements are rejected before they reach the database, and every query is logged.
`Python · OpenAI API · SQLite · function calling`
→ [Repo](https://github.com/simafaramarzi/natural-language-data-query-agent-)

### 3. Profitability Analysis: UK Pet Retail ("Fury Friends")
Profit analysis by store, pet category and month, with Plotly charts and an area-by-pet heatmap. Cats and dogs are the leading profit contributors, and the top store by total profit is Dudley. Based on a provided sample dataset.
`Python · pandas · Plotly · seaborn`
→ [Repo](https://github.com/simafaramarzi/Profitability-Analysis-and-Interactive-Dashboard-for-Pet-Retail-Stores-in-the-UK)

### 4. Berlin Housing Market Analysis

### 5. Customer Segmentation in E-Commerce
Clustering of e-commerce customers using age, annual income and spending score: K-Means (K=4 via elbow method), DBSCAN and hierarchical clustering. K-Means silhouette score: 0.248, which indicates moderate separation.
`Python · pandas · scikit-learn · seaborn`
→ [Repo](https://github.com/simafaramarzi/Customer-Segmentation-in-E-Commerce-Using-Age-and-Annual-Income)

### 6. Cloud Data Pipeline Architecture on AWS (design only)

`AWS · data architecture`
→ [Repo](https://github.com/simafaramarzi/Real-Time-Data-Integration-and-Analytics-in-Real-Estate-Using-AWS-Cloud-Services)

### 7. MNIST: ReLU vs Tanh
Keras neural network (3 hidden layers, 10 epochs, Adam) comparing ReLU and Tanh on convergence speed, accuracy and overfitting. ReLU reached 97.62% train / ~97.8% validation accuracy and converged faster. Tanh reached 97.29% train / ~97.7% validation.
`Python · TensorFlow/Keras · scikit-learn`
→ [Repo](https://github.com/simafaramarzi/MNIST-Digit-Recognition-A-Neural-Network-Approach-with-ReLU-and-Tanh)

`Python · NumPy · pandas · matplotlib`
